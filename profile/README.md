# 🚀 À propos

Game Rank est une plateforme conçue pour aider les joueurs à trouver les meilleurs serveurs et permettre aux propriétaires de communautés de gagner en visibilité.

Nous construisons un écosystème complet autour du gaming :

🎮 Serveurs de jeux  
🏆 Classements intelligents  
⭐ Avis utilisateurs  
👥 Communautés Discord  
📺 Streamers  
🖥️ Hébergeurs  
🛒 Marketplace  
🔌 API publique
